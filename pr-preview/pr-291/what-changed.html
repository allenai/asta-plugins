Reading in Asta

The workspace is a place to read research notes, inspect supporting evidence, and review a paper as it develops. This page shows the shared reading surface in light and dark, including headings, links, tables, code and callouts.

A familiar reading surface

Light mode uses a cream background with dark-teal text. Dark mode uses an extra-dark teal background with cream text. Both come from Asta’s design system, and both use the same Manrope type and page layout. Changing the mode keeps the text in the same place, so you can keep reading where you left off.

The page opens in dark mode on a fresh visit, regardless of your system setting. Use the light/dark toggle in the navigation to choose a mode yourself. Your choice persists as you move between pages or reload the site.

Keep your place

Scroll through this section. Its heading stays above the text until the next section takes over. The table of contents also marks the section you are reading, and its links let you return to a heading directly.

Reading the components

Links use Asta’s teal on the light surface and green on the dark surface. Inline code such as asta workspace sync uses a monospace face. A separate code block keeps commands easy to scan:

asta workspace sync
make check
make preview

Theme toggle Choose the light or dark reading surface
Evidence highlight Inspect the quote backing a research claim

Read the sample literature review to try an evidence highlight. Hover over its marked claim, or focus it with the keyboard, to see the source quote alongside its citation.

Read the sample review

A project can choose its own appearance

The theme is a managed workspace asset. A project receives it from the same selected source as its shared build rules and evidence extension. A refresh updates those assets together instead of leaving a copied stylesheet behind.

Existing projects adopt the Asta theme when their HTML theme still has the scaffold’s original cosmo value and their selected source supplies the new assets. A project with another theme keeps its choice. Older pinned sources keep their original appearance until the project selects a compatible release.

Customize deliberately

For a different HTML theme, edit the project’s _quarto.yml. Keep any project-specific styles alongside it:

format:
  html:
    theme: flatly
    css: styles.css

To customize the Asta theme directly, commit a copy of _extensions/asta-theme. Managed refreshes preserve committed copies and local development symlinks. This keeps intentional project styling under the project’s own version control.

Share the rendered work

A workspace preview includes the same light/dark controls as the published site. Send a reader the preview URL so they can inspect the actual page, follow its links, and choose the reading surface they prefer.

Every page in this workspace is rendered from the repository, so a link to the preview always shows the version under review.

Links between pages

The attention slides present the same question as a short talk. Supporting quotes live in evidence.yml under an id; the literature review’s first claim uses the id transformer-attention.

Attention in sequence models

A short project on how attention replaced recurrence in sequence models. It includes:

  • A literature review of the work it builds on, citing the project’s bibliography.
  • Presentation slides for a short talk on the same question.
  • The paper, written in LaTeX with co-authors in Overleaf.

An example workspace for the Asta workspace skill, built and published from main; see its README for the demo and how to start your own.

A small literature review – Asta workspace example removed

demo/lit-review/index.html

A small literature review

This literature review is the editable Quarto source. To get a PDF or LaTeX source, render it with Quarto (see the workspace guide). This review cites the project-root references.bib. The separate paper/main.tex is edited directly and paired with Overleaf, so it keeps its own copy of the entries it cites.

Example claims

Vaswani and colleagues proposed a Transformer architecture based solely on attention mechanisms“We propose a new simple network architecture, the Transformer, based solely on attention mechanisms”— (Vaswani et al. 2017, abstract) (Vaswani et al. 2017). BERT later applied the Transformer encoder to bidirectional language representation“We introduce a new language representation model called BERT, which stands for Bidirectional Encoder Representations from Transformers.”— (Devlin et al. 2019, abstract) (Devlin et al. 2019). Each highlighted claim shows its source quote on hover or keyboard focus.

References

Devlin, Jacob, Ming-Wei Chang, Kenton Lee, and Kristina Toutanova. 2019. “BERT: Pre-Training of Deep Bidirectional Transformers for Language Understanding.” https://arxiv.org/abs/1810.04805.
Vaswani, Ashish, Noam Shazeer, Niki Parmar, Jakob Uszkoreit, Llion Jones, Aidan N. Gomez, Lukasz Kaiser, and Illia Polosukhin. 2017. “Attention Is All You Need.” https://arxiv.org/abs/1706.03762.
