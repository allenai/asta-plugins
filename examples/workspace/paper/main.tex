\section{A paper paired with Overleaf}
This paper is paired with an Overleaf project, so co-authors can edit it there while the workspace reviews every change in a pull request. Overleaf sees only this \texttt{paper} directory, so the paper keeps its own \texttt{references.bib} here, which co-authors can edit too. Vaswani and colleagues proposed the Transformer, an architecture based solely on attention~\cite{vaswani2017attention}. Its core operation is scaled dot-product attention, $\mathrm{softmax}(QK^\top/\sqrt{d_k})V$. BERT later pre-trained a bidirectional Transformer encoder~\cite{devlin2019bert}. Both entries were copied from the workspace's \texttt{references.bib}, which the companion Quarto page cites.
