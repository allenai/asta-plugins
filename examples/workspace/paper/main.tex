\section{One bibliography}
This example paper and the companion Quarto page both cite the same project bibliography. Vaswani and colleagues proposed the Transformer architecture based on attention mechanisms~\cite{vaswani2017attention}. The citation resolves from the project-root \texttt{references.bib}; no bibliography copy or Overleaf project is required.
